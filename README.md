## 🚦 Getting Started

### Prerequisites
- A modern web browser
- Basic web server (optional, for local development)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/portfolio.git
   cd portfolio
   ```

2. **Open the project**
   - Simply open `index.html` in your web browser
   - Or use a local server like Live Server in VS Code

3. **For development with live reload:**
   ```bash
   # If you have Python installed
   python -m http.server 8000
   
   # If you have Node.js installed
   npx serve .
   ```

4. **Access the site**
   - Direct file: `file://path/to/index.html`
   - Local server: `http://localhost:8000`

## 🎨 Customization

### Updating Content

1. **Personal Information**: Edit the content in `index.html`
2. **Styling**: Modify `assets/css/style.css`
3. **Functionality**: Update `assets/js/script.js`
4. **Resume**: Replace `Faheem Resume.pdf` with your own resume
5. **Images**: Update images in `assets/images/` directory

### Adding Blog Posts

1. Navigate to the `Blogs/` directory
2. Create new HTML files following the existing structure
3. Update the blog index in `Blogs/index.html`

### Theme Customization

The website supports dark and light themes. To customize:

1. Modify CSS custom properties in `style.css`
2. Update theme toggle functionality in `script.js`
